# Cowboy Connections

I want you to build a web app, that will take the attachment as a database. Every time I open the app, it must show me a random item. The project name is "Cowboys don't Cry", use a brown and gold colour scheme. Use the theme: cowboys to decorate the page. The sub heading must be: "Connection Cards", lower down the card must be displayed. Under the card show "You don't have to walk this road alone", right at the bottom of the page show "Find our website at www.anchorandember.co.za"
